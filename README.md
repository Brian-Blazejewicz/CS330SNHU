# CS 330 – Computational Graphics and Visualization

## Project Overview

For my CS 330 final project, I created a 3D outdoor scene using C++ and OpenGL. My scene includes trees, a textured ground, lighting, and camera controls that allow the user to move around and explore the environment. Throughout the course, I worked on different parts of the scene, including creating objects, applying textures, adjusting lighting, and implementing camera movement.

This project helped me better understand how 3D graphics are created and how different parts of a program work together to produce a finished scene.

## How Do I Approach Designing Software?

When designing software, I like to start by understanding what the program needs to accomplish and breaking the work into smaller parts. For this project, I started with the basic shapes needed to create my scene and gradually added more detail.

One of the biggest things I learned was how important it is to plan how objects will look and interact within a 3D environment. I had to consider the placement, size, and appearance of the trees, along with how lighting and textures would affect the overall scene.

I followed a step-by-step design process, making changes as I completed each milestone. In future projects, I can use this same approach to stay organized and make larger assignments easier to manage.

## How Do I Approach Developing Programs?

My approach to developing programs involves writing code, testing it, and making improvements when something does not work as expected. While working on my 3D scene, I learned more about using C++ and OpenGL to create objects, apply textures, and control how the camera moves through the environment.

Iteration was an important part of this project. Each milestone introduced something new, and I had to make sure those changes worked with the code I had already written. There were times when textures did not load correctly or parts of the program needed adjustments. Working through those problems helped me become more comfortable troubleshooting errors.

As the course progressed, I became better at organizing my code and understanding how different files and functions work together. I also learned the importance of testing changes before moving on to the next part of a project.

## How Can Computer Science Help Me in Reaching My Goals?

Computer science is helping me develop the technical and problem-solving skills I will need in my future career. This course introduced me to computational graphics and visualization, which gave me a better understanding of how computers create and display 3D environments.

The skills I learned can be useful in future courses involving programming, software development, and more advanced graphics. Working with C++ also helped me improve my understanding of programming concepts that can be applied to other projects.

Professionally, I can use what I learned about software design, debugging, testing, and organizing code in different areas of software development. Even if I do not work directly with 3D graphics, the experience of building a project from beginning to end will be valuable.

## Final Reflection

Overall, this course helped me become more confident in my ability to work on larger programming projects. Creating a 3D scene required patience, problem-solving, and attention to detail. I learned that developing software is not just about writing code but also about planning, testing, and improving it until everything works together.

I am proud of the progress I made throughout the course and plan to apply these skills to future programming assignments and professional projects.
